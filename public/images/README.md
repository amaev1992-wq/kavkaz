# Изображения сайта

Реальные фотографии «Кавказ-Автогаз» отсутствовали в assets проекта —
на их местах выводятся оформленные placeholder-блоки.

## Какие фотографии нужны

| Файл (рекомендуемое имя)        | Слот                | Что на фото                                                       |
| ------------------------------- | ------------------- | ----------------------------------------------------------------- |
| `hero-station-dusk.jpg`         | Hero                | Современная станция сети вечером, архитектурное освещение         |
| `logistics-tankers.jpg`         | Инфраструктура      | Газовозы компании / газонаполнительная станция                    |
| `station-asset.jpg`             | Реальный актив      | Действующая станция сети, широкий кадр (full-width)               |
| `premium-format.jpg`            | Формат «Премиум»    | Станция с магазином и кафе (опционально)                          |
| `og.jpg` (1200×630)             | Open Graph          | Фото станции для соцсетей                                         |
| `logo.svg` / `logo-white.svg`   | Header/Footer       | Официальный логотип из брендбука (обычный + белая версия)         |
| `suppliers/*.svg`               | Качество топлива    | Официальные логотипы поставщиков (только при праве использования) |

## Как подключить

1. Положите файлы в эту папку (`public/images/`).
2. Фотосекции: укажите `src` в `src/data/images.ts`.
3. Логотип: укажите пути в `src/components/ui/Logo.tsx`.
4. Логотипы поставщиков: укажите `logoSrc` в `src/data/suppliers.ts`.

Рекомендации: JPEG 1600–2400px по длинной стороне, сжатие ~80%.
Все фото выводятся через `object-fit: cover`; точку фокуса можно задать
полем `focal` в `src/data/images.ts`.
